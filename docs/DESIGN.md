## 北极星

一眼知道流量走哪条线路，执行前知道会改什么；浅色深色都清晰可用。

PC 专用网络工作台，主要任务为确认双出口、维护分流规则、预览应用和恢复。验收视口 1440×900、1100×700。分流正确性、可恢复性和按需退出优先。

## 主题体系

- `<html data-theme="light|dark">` 驱动全部颜色；`public/theme-init.js` 在 CSS 加载前读取偏好，默认深色。
- 偏好保存在 host-only `dualnetTheme` cookie（`Path=/`、`SameSite=Strict`、一年），localStorage 同名回退；应用端口随机，cookie 才能跨端口记忆。cookie 只存 `light`/`dark`，无凭证；存储被禁用时界面照常打开。
- 全部颜色为 `public/style.css` 中的语义变量：背景、表面、抬高、悬停、输入底、正文/次级/辅助文字、边框、主色、专用出口色、警示、危险、遮罩、阴影、徽标底。页面内不出现硬编码主题色，不使用组件框架、远程字体或持续动画。
- 浅色：中性灰白底 + 纯白表面；深色：石墨蓝灰底。两主题共用同一套清晰的蓝色主操作（`--accent`），专用出口用青绿色（`--exit2`）区分，警示/危险为柔和的暖色软底。
- 放弃旧版的荧光绿/橄榄色方案。

## 布局

- **横向顶栏**替代旧侧栏：品牌、主导航（分流规则 / 网络设置 / 操作记录）、右侧主题切换按钮与退出管理，腾出完整 PC 工作区。
- 顶栏下为位置条：本地工作空间 / 当前页签名，右侧「配置保存在此电脑」与模式徽章。
- 首页标题区右侧为启用规则计数与「刷新网卡」。
- **两张并排出口卡片**（本机节点在左）：每张卡片展示出口名称（点击铅笔改名）、网卡下拉、连接状态、IPv4 与网关；主出口蓝色顶边、专用出口青绿顶边。窄视口自动换行，长名称省略并保留完整提示。
- 规则表仍是首页最大工作表面：内部滚动，长列表出现「向下查看其余规则」，到底后返回顶部；底部应用动作不遮挡列表。
- 网络设置双列对照（出口名称、网卡、手动网关、专属 DNS）；自动维护单独分组。
- 变更预览固定标题与确认按钮，仅中间内容滚动；新增/撤销/保持按语义色区分。
- 紧凑 PC 视口（≤1260px、≤780px 高）减少间距并调整卡片网格，不缩放整页。

## 任务与状态

- 域名/IP/CIDR/通配网段共用自动识别；粘贴 URL 自动提取有效 IP 或域名，端口、路径及参数不参与路由。
- 配置保存与系统应用明确分开；后台只维护最后成功应用的配置。
- 保存失败保留输入；无规则、无匹配、DNS 失败、过期预览、恢复中断、普通权限、演练及退出均有反馈；错误、禁用、警示与退出全屏状态在两主题下均由变量覆盖。
- 网卡、地址和网关来自实际探测；演练状态明确标识，不伪造连接状态或实时带宽。

## 动效

按钮按下即时反馈；开关 180ms 过渡；页签淡入；弹窗轻位移。业务状态不等动效，尊重 `prefers-reduced-motion`。无拓扑持续动画。
