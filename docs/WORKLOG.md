## 事实与约束

目录只有参考 WinForms/PowerShell 工具，无既有应用、无 Git、无 CodeGraph 索引。Node.js 22 已安装，Python 不在 PATH。

参考工具的优点：零构建、NRPT 指定系统域名 DNS、无线网卡识别。风险：硬编码全私网和 129.0/16；吞掉路由命令失败；无接口索引；按目标删除可能误删用户路由；恢复自动跃点不等于恢复原设置；无事务与所有权记录。新工具不导入其硬编码规则或执行其测试（测试会修改注册表）。

候选任务：Windows 10/11 本地双网卡工具，规则为单 IP / CIDR / 精确域名（URL 自动提取 host），支持两种出口、指定 DNS、系统 DNS 配合、持久配置、路由差异、恢复、自动同步与自启。保持无复杂构建链。默认不写当前机器网络；通过 UI 显式应用。

评分：恢复和所有权 30%；系统域名解析正确性 20%；实现与维护简洁 20%；重试崩溃幂等性 20%；可测性 10%。

候选分别写入 docs/arena/a.md 与 b.md，只产生设计，不递归委派。主代理综合前逐份阅读并评分。
