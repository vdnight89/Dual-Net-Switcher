## 性能与体积测量口径

`node --expose-gc scripts/measure.mjs` 只做真实网卡读取和无策略维护，不改网络。测量管理进程自身，不包括浏览器和瞬时 PowerShell 子进程。最新数值见 `evidence/performance.json`：Node RSS 约 55.5 MiB、JS 堆实际使用约 6.9 MiB；启动真实网卡探测约 4.3 秒。未配置策略的一次维护在现有 Node 进程内跳过逻辑约 2ms，不包含操作系统启动 Node 的开销。

退出管理后无本工具服务进程；计划任务每次启动临时进程并退出，不能把任务执行期间描述为零内存。实际 DNS、系统写入耗时取决于网卡和服务器。无前端依赖、构建产物、第三方字体、图片下载；便携 ZIP 不包含 Node 运行时、参考项目、数据、截图和视频。
